egui_html_view

An HTML + CSS widget for egui

This page is rendered natively by egui: no browser engine, no native webview. Text can be selected with the mouse and copied with Ctrl+C; use Ctrl + mouse wheel to zoom.

Inline styles: underline, strike-through, highlight, inline code, H2O, E = mc2,  badge , small and big text. Links: jump to the table or egui on GitHub.

Card. Backgrounds, borders, rounded corners, padding and CSS variables (var(--accent)) are supported.
